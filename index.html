Automatización de RFPs | Apps Script

Aplicación empresarial que automatiza el análisis y la redacción de respuestas a solicitudes de propuestas (RFPs) en minutos mediante la API de Gemini (3.5-flash). Integra un sistema de subida y procesamiento directo de documentos con clasificación por niveles de confianza, exportación en PDF y un chatbot interactivo para consultas técnicas en tiempo real. Cuenta con un frontend alojado en Google Apps Script con arquitectura serverless y delegación segura de permisos.

02

Pipeline ETL Automatizado | n8n

Workflow en n8n diseñado para automatizar el ciclo completo de extracción, transformación y carga (ETL) de datos de ventas desde HubSpot hacia Google Sheets. Normaliza identificadores complejos de pipelines, etapas y propietarios a nombres legibles, ejecutando además un microservicio en Python dentro de Docker para limpieza avanzada y cálculo de métricas temporales. Mantiene la base de datos libre de duplicados y optimizada para alimentar tableros de visualización.

SerfiApp | Colaborativo

Proyecto ganador del 1er lugar en la Hackatón Barranqui-IA 2026 (Categoría Fintech), creado para transformar la atención bancaria omnicanal. Orquesta agentes de IA proactivos para agilizar el servicio al cliente con RAG, hiper-personalizar la venta de productos financieros según comportamiento transaccional y ejecutar ofertas por geolocalización.

Proyecto hecho por equipo Dockers. Diseñé la lógica de los agentes de Ventas y Servicio al Cliente, la arquitectura de base de datos y la presentación técnica ante el jurado experto.
